# История изменений

Здесь описаны изменения для пользователей и требования к совместимости.

## Unreleased

- Настроена публикация новых версий из одного git-тега в ClawHub и npm.

## 26.1.6

- Обработка личных сообщений переведена на асинхронный API OpenClaw SDK; удалён устаревший импорт `conversation-runtime`.
- **Требуется OpenClaw `2026.11.7` или новее.**

## 26.1.5

- Добавлена автоматическая публикация в ClawHub по git-тегу. Workflow проверяет версию, собирает и валидирует архив; ручной запуск выполняет пробный прогон.

## 26.1.4

### Patch Changes

- отображаемое имя плагина изменено на VK Teams Bot;
- исправлено направление уведомлений об одобрении pairing: токен отправляется только на API-адрес своего аккаунта;
- для запросов к Bot API требуется HTTPS без перенаправлений; необработанные описания ошибок API не выводятся.

## 26.1.3

### Patch Changes

- добавлено отображаемое имя VK Teams в манифест плагина;
- закреплены версии Node.js и pnpm для воспроизводимой сборки, npm-пакет собирается перед публикацией.

## 26.1.2

### Patch Changes

- добавлен индикатор набора текста для входящих личных сообщений;
- исходящие ответы VK Teams теперь отправляются без Markdown-разметки;
- добавлена поддержка приёма изображений из личных сообщений через VK Teams Bot API (`/files/getInfo`), с подписью или без неё.
